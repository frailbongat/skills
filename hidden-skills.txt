# Skills hidden from the agent's system prompt.
#
# hide-skills.sh stamps `disable-model-invocation: true` into each skill listed
# here. A hidden skill is still installed and still works, it just costs no
# tokens until you run `/skill:<name>` or an agent reads its SKILL.md by path.
#
# Why: 44 visible skills cost ~5,100 tokens of every single session, and the
# design cluster was ~3,100 of that. Most of those entries are near-duplicates
# of each other ("make the frontend look premium"), so they were paying twice,
# once in tokens and once in bad skill choices.
#
# Rules for this list:
#   - Never hide a skill another VISIBLE skill hands work to by name.
#   - Never hide a skill a live project names in its own docs or prompts,
#     unless agents there read named skills by path.
#   - One name per line. Blank lines and # comments are ignored.
#
# Kept visible on purpose:
#   impeccable                    broadest design entry point, covers the rest
#   security-audit                vendored and patched, model-invoked so the agent
#                                 reaches it when auth, input handling, or secrets
#                                 come up (commit 9b604bd)
